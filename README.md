# Chat GPT AI Clone

Chat GPT AI Clone is a web application that allows users to search for answers to any questions using the Chat GPT 3.5 engine. This project leverages modern frontend technologies such as React, SCSS, and RESTful APIs to deliver an intuitive and responsive user experience.

![enter image description here](https://akin-gungor.vercel.app/assets/chatgpt-ba2b377a.png)
## Features

- **Interactive Search**: Users can input any question and receive answers powered by the Chat GPT 3.5 engine.
- **Responsive Design**: The application is fully responsive, ensuring usability across various devices and screen sizes.
- **Modern UI**: Styled using SCSS for a sleek and modern look.

## Technologies Used

- **React**: A JavaScript library for building user interfaces.
- **REST API**: To interact with the Chat GPT 3.5 engine and fetch responses.
- **SCSS**: A CSS preprocessor to write more maintainable and scalable stylesheets.

## Usage

1.  Open your browser and navigate to `http://localhost:3000`.
2.  Enter your question in the search bar.
3.  Press the search button to get answers from the Chat GPT 3.5 engine.
